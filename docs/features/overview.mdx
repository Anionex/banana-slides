## The Workflow

```
Create Project → Edit Outline → Write Descriptions → Generate Images → Export
```

Every step supports AI assistance and manual fine-tuning.

## Presentation Studio

The home page introduces "Your ideas. Beyond templates." Four creation paths use clearer names:

- **An idea**: Enter a topic, audience, and requirements, with optional reference materials.
- **An outline**: Start with an existing structure and continue to outline editing.
- **Slide content**: Provide descriptions for each slide, using the existing description-parsing workflow.
- **An existing deck**: Upload an existing PDF/PPTX/PPT, using the existing renovation workflow.

Click "Explore styles" to jump to the style settings without changing routes or clearing your content. Preset templates support keyboard selection, and their thumbnails show the full image. You can also switch to a written style description or independent templates for each slide. Selecting a style does not trigger any additional AI generation.

"Pick up where you left off" shows your 3 most recent projects. Click one to continue editing based on its existing content. If there are no projects, a prompt helps you get started. If loading fails, a retry option appears instead of incorrectly reporting that there are no projects. You can still manage more projects under "All projects".

The editor header shows the project name, slide count, and current stage. The stage indicator explains your position; it is not a shortcut for skipping steps. Continue using the existing "Previous" and "Next" controls to preserve saving and generation requirement checks.

### Appearance and Motion

- Warm white, ink black, and banana yellow define the light interface. Dark mode and system theme support remain available.
- On mobile, "More tools" in the top-right corner groups the Material Generator, Material Center, settings, help, language, and system theme option. Adjacent controls open project history or switch between light and dark mode directly.
- Entrances, hover states, and dialogs use brief feedback. Examples on the brand page change only when clicked and no longer rotate automatically.
- When the system's reduced-motion preference is enabled, decorative entrances and smooth scrolling are disabled, and other transitions are shortened. Loading and generation status remain visible as text.

This update does not change AI service settings, generation counts, saving workflows, or export formats, and does not add automatic trial generation.

## Four Creation Paths

| Path | Best for |
|------|---------|
| From an idea | Just a topic — let AI generate everything |
| From an outline | You have an existing structure |
| From descriptions | Content is already clear, generate images directly |
| PPT Renovation | Upload an old PPT, AI regenerates a fresh version |

See [Creating a Presentation](/features/creation).

## AI-Assisted Editing

Every editing step has a top input bar — tell AI what to do in plain language:

- **Outline Editor**: `Add a competitive analysis section after page 3`
- **Description Editor**: `Make all descriptions more detailed with specific text content`
- **Slide Preview** (single page): `Change the background to dark blue, increase title font size`

See [Edit Outline](/features/outline), [Write Descriptions](/features/descriptions), [Generate & Refine Images](/features/images).

## Material Support

- Upload reference files (PDF, DOCX, PPTX, spreadsheets, etc.) — AI extracts content to inform generation
- Paste images — AI recognizes content and inserts them
- Use the **Material Generator** to create custom backgrounds or illustrations with AI
- **Material Center** manages all your materials for easy reuse

See [Materials & Files](/features/materials).

## Export

- **PPTX**: Slides embedded as images, playable and reorderable in PowerPoint
- **Editable PPTX (Beta)**: Text extracted as native text boxes, editable in PowerPoint
- **PDF**: Pixel-perfect output
- **Images**: Each page as an individual file

Multiple aspect ratios supported, with selective page export. See [Export Options](/features/export).
