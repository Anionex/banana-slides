## 프로젝트의 시작
당신도 이런 곤경에 처한 적이 있나요? 내일이 발표인데 PPT는 여전히 백지 상태이고, 머릿속에는 수많은 멋진 아이디어가 가득하지만 번거로운 레이아웃과 디자인 때문에 열정이 다 식어버린 적 말이죠.

저(희)는 전문적이면서도 디자인 감각이 살아있는 프레젠테이션을 빠르게 제작하고 싶었습니다. 기존의 AI PPT 생성 앱들은 '빠르다'는 요구사항은 대체로 충족하지만, 다음과 같은 문제점들이 있었습니다:

- 1️⃣ 프리셋 템플릿만 선택 가능하며, 스타일을 유연하게 조정할 수 없음
- 2️⃣ 자유도가 낮아 여러 차례 수정하기 어려움
- 3️⃣ 결과물의 느낌이 비슷비슷하여 동질화가 심함
- 4️⃣ 소재의 품질이 낮고 타겟팅이 부족함
- 5️⃣ 이미지와 텍스트의 레이아웃이 따로 놀고 디자인 감각이 떨어짐

이러한 결함들 때문에 기존의 AI PPT 생성기로는 '빠름'과 '아름다움'이라는 PPT 제작의 두 가지 핵심 요구사항을 동시에 만족시키기 어려웠습니다. 스스로 Vibe PPT라고 자처하더라도, 제 눈에는 아직 'Vibe'가 한참 부족해 보였습니다.

하지만 nano banana🍌 모델의 등장이 모든 것을 바꿔놓았습니다. 🍌pro를 사용하여 PPT 페이지를 생성해 본 결과, 품질, 미적 감각, 일관성 면에서 모두 매우 뛰어났으며, 프롬프트가 요구하는 거의 모든 텍스트를 정확하게 렌더링하고 참고 이미지의 스타일을 잘 따랐습니다. 그렇다면 🍌pro를 기반으로 네이티브 "Vibe PPT" 앱을 만들어보는 건 어떨까요?

## 👨‍💻 활용 사례


1. **초보자**: 진입 장벽 없이 아름다운 PPT를 빠르게 생성하며, 디자인 경험이 없어도 템플릿 선택의 고민을 덜어줍니다.
2. **PPT 전문가**: AI가 생성한 레이아웃과 텍스트/이미지 요소 조합을 참고하여 디자인 영감을 빠르게 얻을 수 있습니다.
3. **교육 종사자**: 교육 내용을 이미지가 포함된 강의안 PPT로 빠르게 변환하여 수업 효과를 높입니다.
4. **학생**: 과제 발표를 빠르게 완성하고, 레이아웃 디자인보다는 내용에 더 집중할 수 있습니다.
5. **직장인**: 비즈니스 제안서, 제품 소개 등을 빠르게 시각화하고 다양한 상황에 즉시 적용할 수 있습니다.

## 🎯 기능 소개

### 1. 유연하고 다양한 창작 경로
**아이디어**, **개요**, **페이지 설명**의 세 가지 시작 방식을 지원하여 서로 다른 창작 습관을 충족합니다.
- **한 문장 생성**: 주제를 입력하면 AI가 구조가 명확한 개요와 페이지별 내용 설명을 자동으로 생성합니다.
- **자연어 편집**: Vibe 형식으로 개요나 설명을 구두로 수정(예: "세 번째 페이지를 사례 분석으로 변경해 줘")할 수 있으며, AI가 실시간으로 응답하여 조정합니다.
- **개요/설명 모드**: 클릭 한 번으로 일괄 생성하거나 세부 사항을 수동으로 조정할 수 있습니다.

### 2. 강력한 소재 분석 능력

2. **서비스 시작**

**⚡ 사전 빌드 이미지 사용(권장)**

Docker Hub에 미리 빌드된 프런트엔드 및 백엔드 이미지가 제공되며, 메인 브랜치의 최신 버전과 동기화됩니다. 로컬 빌드 단계를 건너뛰고 빠르게 배포할 수 있습니다.

```bash
# 使用预构建镜像启动（无需从头构建）
docker compose -f docker-compose.prod.yml up -d
```
이미지 이름:
- `anoinex/banana-slides-frontend:latest`
- `anoinex/banana-slides-backend:latest`

시작 후 앱에서 **설정 → 정보 → 업데이트 확인**으로 이동할 수 있습니다. 앱은 현재 버전 SHA를 기준으로 업데이트 가능 여부를 판단하며, 소스 코드로 실행할 때도 현재 Git SHA를 사용합니다.

**이미지를 직접 빌드하기**

```bash
docker compose up -d
```

> [!TIP]
> 네트워크 문제가 발생하면 `.env` 파일에서 미러 설정의 주석을 해제한 뒤 시작 명령을 다시 실행하세요.
> ```env
> # 在 .env 文件中取消以下注释即可使用国内镜像源
> DOCKER_REGISTRY=docker.1ms.run/

> NPM_REGISTRY=https://registry.npmmirror.com/
> ```

### 소스 코드에서 배포

<!-- i18n:requirements -->
#### 환경 요구 사항
- Python 3.10 이상
- [uv](https://github.com/astral-sh/uv) - Python 패키지 관리자
- Node.js 16+ 및 npm
- [FFmpeg](https://ffmpeg.org/) - 해설 영상 내보내기에 필수이며, `libass` / `ass` 자막 필터 지원이 포함되어야 함
- 유효한 Google Gemini API 키
- (선택 사항) [LibreOffice](https://www.libreoffice.org/) - 「PPT 리노베이션」 기능을 사용하여 PPTX 파일을 업로드할 때 필요하며, PPTX를 PDF로 변환하는 데 사용됩니다. **가급적 로컬에서 PPTX를 PDF로 변환한 후 업로드하는 것을 권장합니다.** 이유: LibreOffice는 서버 측 렌더링 시 글꼴(예: 맑은 고딕, Calibri 등) 부족으로 인해 레이아웃이 어긋날 수 있으며, 일부 특수 효과를 완벽하게 복원하지 못할 수 있습니다. PDF 파일을 업로드하는 경우에는 LibreOffice가 필요하지 않습니다. Docker 사용자가 컨테이너 내에서 PPTX 업로드를 지원해야 하는 경우 다음을 실행할 수 있습니다:
  ```bash
  docker exec -it banana-slides-backend bash -c "apt-get update && apt-get install -y libreoffice-impress && rm -rf /var/lib/apt/lists/*"
  ```
  > 주의: 이 방식으로 설치된 LibreOffice는 컨테이너 재빌드 시 삭제되므로 다시 설치해야 합니다.

<!-- i18n:backend -->
#### 백엔드 설치

0. **코드 저장소 클론**
```bash
git clone https://github.com/Anionex/banana-slides
cd banana-slides
```

1. **uv 설치 (아직 설치되지 않은 경우)**
```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
```

2. **의존성 설치**

프로젝트 루트 디렉터리에서 실행:
```bash
# macOS（Homebrew）
brew install ffmpeg-full
brew unlink ffmpeg 2>/dev/null || true
brew link --overwrite --force ffmpeg-full

# Ubuntu / Debian
sudo apt-get update
sudo apt-get install -y ffmpeg libass9

# 然后安装 Python 依赖
uv sync
```

이것은 `pyproject.toml`에 따라 모든 의존성을 자동으로 설치합니다.

3. **환경 변수 설정**

환경 변수 템플릿 복사:
```bash
cp .env.example .env
# 然后按照前述方法，打开编辑 `.env` 文件，配置你的 API 密钥
```

<!-- i18n:frontend -->
#### 프론트엔드 설치

1. **프론트엔드 디렉터리로 이동**
```bash
cd frontend
```

2. **의존성 설치**
```bash
npm install
```

3. **API 주소 설정**

프론트엔드는 Vite proxy를 통해 `BACKEND_PORT`에 지정된 백엔드 서비스(기본값 `http://localhost:5011`)에 자동으로 연결됩니다. 수정이 필요한 경우, 프로젝트 루트 디렉터리의 `.env`에서 `BACKEND_PORT`를 설정하십시오.

<!-- i18n:start-backend -->
#### 백엔드 서비스 시작
> (선택 사항) 로컬에 중요한 데이터가 있는 경우, 업그레이드 전에 데이터베이스를 백업하는 것을 권장합니다:  
> `cp backend/instance/database.db backend/instance/database.db.bak`
> 비고: 기본 설정 시 템플릿, 소재, 결과물은 모두 uploads/ 폴더에 저장됩니다.

```bash
cd backend
uv run alembic upgrade head && uv run python app.py
```

백엔드 서비스가 `http://localhost:5011`에서 시작됩니다.

`http://localhost:5011/health`에 접속하여 서비스가 정상적으로 작동하는지 확인하십시오.

<!-- i18n:start-frontend -->
#### 프론트엔드 개발 서버 시작

```bash
cd frontend
npm run dev
```

프론트엔드 개발 서버가 `http://localhost:3011`에서 시작됩니다.

브라우저를 열고 접속하여 애플리케이션을 사용할 수 있습니다.
