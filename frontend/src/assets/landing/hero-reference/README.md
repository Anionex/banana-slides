# Hero reference material

Four independent full-sheet opacity fields fitted to the broad colour distribution of the user-supplied design screenshot (814 × 908). The CSS rectangles supply geometry and clipping; no intersection regions are painted as separate shapes.

Grain uses the shared `heroGrain.ts` bitmap and the same 256px tile, overlay blend and intensity as FooterRibbon. The base yellow `#ffd52c` retains the average colour of the previous screen-blended reference texture, so changing grain does not deepen the colour fields. The first sheet includes a fading white surface to occlude the second sheet's upper-left edge.
