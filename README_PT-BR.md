## Origem do Projeto
Você já se viu nesta situação: a apresentação é amanhã, mas o PPT ainda está em branco; sua mente está cheia de ideias brilhantes, mas todo o seu entusiasmo é consumido pela formatação e pelo design tediosos?

Eu (nós) desejo(amos) criar rapidamente apresentações que sejam profissionais e tenham um bom design. Os aplicativos tradicionais de geração de PPT por IA, embora atendam amplamente à demanda por "rapidez", ainda apresentam os seguintes problemas:

- 1️⃣ Só permitem escolher modelos predefinidos, sem flexibilidade para ajustar o estilo
- 2️⃣ Baixo nível de liberdade, dificultando a realização de múltiplas rodadas de alterações 
- 3️⃣ O visual dos produtos finais é muito semelhante, com uma homogeneização severa
- 4️⃣ A qualidade dos materiais é baixa e falta especificidade
- 5️⃣ A diagramação de texto e imagem é fragmentada, com pouco senso de design

Essas deficiências tornam difícil para os geradores de PPT por IA tradicionais satisfazerem simultaneamente nossas duas grandes necessidades na criação de PPTs: "rapidez" e "beleza". Mesmo aqueles que se autodenominam Vibe PPT, aos meus olhos, ainda não são "Vibe" o suficiente.

No entanto, o surgimento do modelo nano banana🍌 mudou tudo. Tentei usar o 🍌pro para gerar páginas de PPT e descobri que os resultados foram excelentes em termos de qualidade, estética e consistência, sendo capaz de renderizar com precisão quase todo o texto solicitado pelo prompt e seguir o estilo da imagem de referência. Então, por que não criar um aplicativo "Vibe PPT" nativo baseado no 🍌pro?

<!-- i18n:audience -->
## 👨‍💻 Cenários de Uso


1. **Iniciantes**: Geração rápida de PPTs estéticos com barreira zero, sem necessidade de experiência em design, reduzindo a preocupação com a escolha de modelos
2. **Profissionais de PPT**: Referência de layouts e combinações de elementos gráficos e textuais gerados por IA, obtendo inspiração de design rapidamente
3. **Educadores**: Conversão rápida de conteúdos de ensino em PPTs de planos de aula ilustrados, melhorando o efeito em sala de aula
4. **Estudantes**: Conclusão rápida de apresentações de trabalhos, focando a energia no conteúdo em vez da formatação e estética
5. **Profissionais**: Visualização rápida de propostas comerciais e apresentações de produtos, com adaptação rápida a múltiplos cenários

<p>
  <b>🎯Objetivo: Reduzir a barreira de criação de PPTs, permitindo que todos possam criar apresentações estéticas e profissionais rapidamente</b>
</p>

## 🎯 Funcionalidades

<!-- i18n:creation -->
### 1. Caminhos de criação flexíveis e variados
Suporta três formas de começar: **ideias**, **esboços** e **descrições de página**, atendendo a diferentes hábitos de criação.
- **Geração com uma única frase**: Insira um tema e a IA gera automaticamente um esboço com estrutura clara e descrições de conteúdo página por página.
- **Edição em linguagem natural**: Suporta a modificação verbal de esboços ou descrições via Vibe (ex: "altere a terceira página para um estudo de caso"), com a IA respondendo aos ajustes em tempo real.
- **Modo Esboço/Descrição**: Permite tanto a geração em lote com um clique quanto o ajuste manual de detalhes.

<img width="2000" height="1125" alt="image" src="https://github.com/user-attachments/assets/7fc1ecc6-433d-4157-b4ca-95fcebac66ba" />

<!-- i18n:assets -->
### 2. Poderosa capacidade de análise de materiais
- **Suporte a múltiplos formatos**: Carregue arquivos PDF/Docx/MD/Txt e o sistema analisará o conteúdo automaticamente em segundo plano.
- **Extração inteligente**: Identifica automaticamente pontos-chave, links de imagens e informações de gráficos no texto, fornecendo materiais ricos para a geração.
- **Armazenamento automático de imagens**: As imagens extraídas dos documentos entrarão automaticamente na biblioteca de materiais do projeto após o arquivo de referência ser associado ao projeto, podendo ser reutilizadas diretamente no futuro.
- **Referência de estilo**: Suporte para upload de imagens de referência ou modelos para personalizar o estilo do PPT.

<img width="1920" height="1080" alt="文件解析与素材处理" src="https://github.com/user-attachments/assets/8cda1fd2-2369-4028-b310-ea6604183936" />

<!-- i18n:editing -->
### 3. Edição em linguagem natural estilo "Vibe"
Não se limite mais a botões de menu complexos; dê comandos de edição diretamente através de **linguagem natural**.
- **Redesenho parcial**: faça modificações verbais em áreas insatisfatórias (ex: "troque este gráfico por um gráfico de pizza").
- **Otimização de página inteira**: gere páginas em alta definição e com estilo unificado baseadas no nano banana pro🍌.

<img width="2000" height="1125" alt="image" src="https://github.com/user-attachments/assets/929ba24a-996c-4f6d-9ec6-818be6b08ea3" />

### 4. Exportação de formatos pronta para uso
- **Suporte a múltiplos formatos**: exportação em um clique de arquivos **PPTX** ou **PDF** padrão.
- **Configurações de reprodução**: antes de exportar para PPTX, é possível ativar animações de transição de página, com suporte a efeitos clássicos como esmaecimento.
- **Adaptação perfeita**: proporção padrão 16:9, sem necessidade de ajustes secundários de layout, pronto para apresentação direta.

### Usando Docker Compose🐳
Inicie rapidamente os serviços de front-end e back-end via Docker Compose.

<details>

Se você estiver usando **Windows ou macOS**, primeiro [instale o **Docker Desktop**](https://docs.docker.com/desktop/setup/install/windows-install/) e certifique-se de que o Docker esteja em execução (no Windows, verifique o ícone na bandeja do sistema; no macOS, verifique o ícone na barra de menus) e siga as mesmas etapas do documento.

> **Dica**: Se encontrar problemas, usuários de Windows devem habilitar o **back-end WSL 2** nas configurações do Docker Desktop (recomendado); certifique-se também de que as portas **3011** e **5011** não estejam ocupadas.

### Implantação a partir do código-fonte

<!-- i18n:requirements -->
#### Requisitos do ambiente
- Python 3.10 ou superior
- [uv](https://github.com/astral-sh/uv) - Gerenciador de pacotes Python
- Node.js 16+ e npm
- [FFmpeg](https://ffmpeg.org/) - Necessário para a exportação de vídeos explicativos, e deve incluir suporte aos filtros de legenda `libass` / `ass`
- Uma chave de API válida do Google Gemini
- (Opcional) [LibreOffice](https://www.libreoffice.org/) - Necessário ao usar a função "Renovação de PPT" para upload de arquivos PPTX, utilizado para converter PPTX em PDF. **Recomenda-se converter o PPTX para PDF localmente antes de fazer o upload**, motivo: o LibreOffice pode causar erros de layout durante a renderização no servidor devido à falta de fontes (como Microsoft YaHei, Calibri, etc.) e não consegue restaurar completamente alguns efeitos especiais. O upload de arquivos PDF não requer o LibreOffice. Usuários de Docker que ainda precisarem de suporte para upload de PPTX dentro do contêiner podem executar:
  ```bash
  docker exec -it banana-slides-backend bash -c "apt-get update && apt-get install -y libreoffice-impress && rm -rf /var/lib/apt/lists/*"
  ```
  > Observação: O LibreOffice instalado desta forma será perdido após a reconstrução do contêiner e precisará ser reinstalado.

#### Instalação do Backend

0. **Clonar o repositório de código**
```bash
git clone https://github.com/Anionex/banana-slides
cd banana-slides
```

1. **Instalar o uv (se ainda não estiver instalado)**
```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
```

2. **Instalar dependências**

Execute no diretório raiz do projeto:
```bash
# macOS（Homebrew）
brew install ffmpeg-full
brew unlink ffmpeg 2>/dev/null || true
brew link --overwrite --force ffmpeg-full

# Ubuntu / Debian
sudo apt-get update
sudo apt-get install -y ffmpeg libass9

# 然后安装 Python 依赖
uv sync
```

Isso instalará automaticamente todas as dependências de acordo com o `pyproject.toml`.

3. **Configurar variáveis de ambiente**

Copie o modelo de variáveis de ambiente:
```bash
cp .env.example .env
# 然后按照前述方法，打开编辑 `.env` 文件，配置你的 API 密钥
```

<!-- i18n:frontend -->
#### Instalação do Front-end

1. **Acesse o diretório do front-end**
```bash
cd frontend
```

2. **Instale as dependências**
```bash
npm install
```

3. **Configure o endereço da API**

O front-end se conectará automaticamente ao serviço de back-end especificado em `BACKEND_PORT` via Vite proxy (padrão `http://localhost:5011`). Se precisar modificar, configure `BACKEND_PORT` no arquivo `.env` na raiz do projeto.

<!-- i18n:start-backend -->
#### Iniciar o serviço de back-end
> (Opcional) Se houver dados locais importantes, recomenda-se fazer o backup do banco de dados antes da atualização:  
> `cp backend/instance/database.db backend/instance/database.db.bak`
> Observação: Na configuração padrão, modelos, materiais e produtos finais estão todos na pasta uploads/

```bash
cd backend
uv run alembic upgrade head && uv run python app.py
```

O serviço de back-end será iniciado em `http://localhost:5011`.

Acesse `http://localhost:5011/health` para verificar se o serviço está funcionando normalmente.

<!-- i18n:start-frontend -->
#### Iniciar o servidor de desenvolvimento front-end

```bash
cd frontend
npm run dev
```

O servidor de desenvolvimento front-end será iniciado em `http://localhost:3011`.
